# 🧪 Laboratory Website – Illumelabs Diagnostic Center

A clean and responsive laboratory website designed to provide information about diagnostic and medical testing services. This project features a simple user-friendly interface with dedicated sections for the home page, about page, blog, and contact information.

## 🌐 Live Demo

[Visit Website]([https://kohinoornarwal-bit.github.io/labouratory1/](https://kohinoornarwal.github.io/labouratory1/))

## 📌 About The Project

The **Illumelabs Diagnostic Center Website** is a frontend web development project created using HTML and CSS.

The website represents a diagnostic laboratory and provides visitors with information about laboratory services, testing facilities, and the organization.

The main goal of this project is to create a simple, informative, and visually appealing website for a diagnostic center.

## ✨ Features

- 🏠 **Home Page** – Introduction to the diagnostic center.
- ℹ️ **About Page** – Information about the laboratory.
- 📰 **Blog Page** – Dedicated section for articles and updates.
- 📞 **Contact Page** – Contact information for visitors.
- 🩸 **Hematology** – Information about blood testing.
- 🧬 **Pathology & DNA** – Diagnostic testing information.
- 🩻 **X-Ray** – X-ray service information.
- 💻 **Simple UI** – Clean and easy-to-use website design.
- 📱 **Website Assets** – Organized CSS, fonts, and images.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/kohinoornarwal/labouratory1.git
```

### 2. Open the Project Folder

```bash
cd labouratory1
```

### 3. Run the Website

Open `index.html` in your browser.

Alternatively, use the VS Code Live Server extension to run the website locally.
